dere private

moonsorter

browser ranking via the plackett-luce model. pairwise comparisons, MM fitting, k-means tiers. moonbit · wasm · astro

verbum-diei

daily lectionary site. vatican rss, a local douay-rheims, and the liturgical calendar, regenerated nightly. typescript · purescript · bun

alpm hook that trust-scores an AUR package before pacman commits — pkgbuild, sources, maintainer and git history. rust · alpm · arch
