── projects §02

dere private

persona-layered claude code wrapper. a daemon holds sessions, emotions, and a knowledge graph; plugins add workflow-specific behavior. typescript · bun · postgres · falkordb

magi

a compiled language for business-data reconciliation. source contracts, type checking and a plan, executed on an embedded duckdb; exports excel, parquet, or a power bi semantic model. rust · duckdb · lsp

sql2m

turns a duckdb SELECT into a power query M step chain, one named step per operation. runs the query against deliberately nasty fake data so join fan-out is visible. no backend. moonbit · wasm · duckdb

sql-grind

65 sql challenges over 13 skills, including measured plan labs and reconciliation drills. duckdb-wasm, so the whole desk runs in the browser. svelte · typescript · duckdb

moongate

ci gate for the rules a linter cannot see — "never log credentials", "migrations must be reversible" — scored against a pr diff and posted as annotations. moonbit · jev · actions

factorio-buddy

one autonomous npc that plays factorio beside you: observes, walks, mines, crafts, builds, and answers messages from an in-game panel. rust · lua · rcon

wf-recorder-control

gtk4 front end for wf-recorder on wayland. on niri it records a chosen window through the screencast portal, following it as it moves or gets covered. c · gtk4 · pipewire

moonsorter

browser ranking via the plackett-luce model. pairwise comparisons, MM fitting, k-means tiers. moonbit · wasm · astro

verbum-diei

daily lectionary site. vatican rss, a local douay-rheims, and the liturgical calendar, regenerated nightly. typescript · purescript · bun

bewaur

alpm hook that trust-scores an AUR package before pacman commits — pkgbuild, sources, maintainer and git history. rust · alpm · arch

lector

turns an epub or pdf into a read-along audiobook — chaptered m4b plus word-synced subtitles, timed off the synthesis model. rust · onnx · kokoro · ffmpeg

benkyou-yaro

builds a prerequisite graph for a new domain, then splits practice into cards for facts and graded exercises for skills. rust · anki

moonbit ecosystem

standalone moonbit libraries: moontrace (structured tracing with otlp export) and tempo (utc datetime + rfc 3339). moonbit · wasm
